# Tuo Yang

Data Engineer based in Helsinki, Finland.

I work with Python and SQL on data pipelines, business system integration, and analytics. At Goldencrop, I worked on production integrations between Odoo ERP and Magento, handling product, inventory, pricing, and order data. The work involved asynchronous processing, validation, recovery, and adapting to changes in upstream systems. One synchronization workflow went from around two hours to fifteen minutes.

My portfolio projects build on that experience. I focus on making data pipelines reliable and their outputs useful to the people who depend on them.
